# ECG_classification_entropy

Este é o repositório do código implementado no projeto intitulado: "Medidas de Entropia e Inteligência Artificial para a Detecção de Arritmias Cardíacas em Sinais de ECG", submetido ao 26º SIMPÓSIO BRASILEIRO DE
COMPUTAÇÃO APLICADA À SAÚDE (SBCAS 2026), a ser realizado em Ouro Preto/MG, de 01 a 4 de junho de 2026.

Em função do processo de double-blind peer review alguns detalhes suprimidos, mas serão novamente disponibilizados após a finalização dessa etapa.
